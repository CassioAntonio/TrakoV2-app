# Trailblazer App

# 🏍️ TRAKO — YOUR RIDE. YOUR TRAIL.

Crie um **aplicativo mobile real de trilhas e motociclismo off-road**, chamado **TRAKO**.

O TRAKO será uma plataforma para motociclistas que praticam:

* Off-road
* Trail
* Enduro
* Hard Enduro
* Rally
* Adventure
* Dual Sport
* Motocross
* Passeios e exploração

A proposta é combinar:

**GPS + MAPAS + TRILHAS + TRACKING + ESTATÍSTICAS + COMUNIDADE + AVENTURA**

O TRAKO é inspirado conceitualmente em aplicativos esportivos e de navegação como Strava, Komoot, Wikiloc e Garmin Connect, mas deve possuir **identidade visual, experiência, arquitetura e produto próprios**.

Não copie identidade visual, textos, imagens, código ou componentes proprietários de nenhum desses aplicativos.

---

# 🚨 REGRA PRINCIPAL DO PROJETO

O TRAKO é um **APLICATIVO MOBILE**.

NÃO crie uma landing page.

NÃO transforme o projeto em um website institucional.

NÃO crie uma página de marketing apresentando o produto.

O usuário deve sentir que está usando um aplicativo instalado no celular.

A experiência deve ser:

**Abrir aplicativo → entrar automaticamente → Home → Explorar → Gravar → Finalizar → Estatísticas → Histórico → Perfil**

O produto deve possuir **telas reais, navegação real e funcionalidades conectadas**.

# 📍 LOCALIZAÇÃO REAL DO USUÁRIO

O TRAKO deve utilizar a **localização real do dispositivo**.

NÃO utilizar localização fixa.

Itaú de Minas - MG pode ser utilizado durante desenvolvimento/testes, mas nunca deve ser tratado como localização padrão do produto.

O aplicativo deve funcionar para qualquer usuário:

* Itaú de Minas;
* Passos;
* São Paulo;
* Minas Gerais;
* qualquer estado;
* qualquer cidade;
* qualquer país.

Se o piloto viajar de Itaú de Minas para São Paulo, por exemplo, o aplicativo deve detectar a nova localização e atualizar a experiência.

---

# 🌎 LOCALIZAÇÃO GLOBAL

A localização deve ser totalmente dinâmica.

Utilizar latitude e longitude do dispositivo.

A localização atual deve determinar:

* Posição no mapa;
* Trilhas próximas;
* Rotas próximas;
* Pontos de interesse;
* Região de exploração.

Não criar regras específicas para uma cidade.

Não definir coordenadas fixas.

---

# 🔐 PERMISSÃO DE LOCALIZAÇÃO

Quando uma funcionalidade precisar da localização, solicitar a permissão apropriada.

Explicar ao usuário por que a localização é necessária.

Exemplo:

**"O TRAKO precisa acessar sua localização para mostrar sua posição no mapa, encontrar trilhas próximas e registrar suas atividades."**

Respeitar a decisão do usuário.

Caso a permissão seja negada, mostrar estado apropriado e permitir que o usuário tente novamente.

**42 km**

Não utilizar números pré-preenchidos.
